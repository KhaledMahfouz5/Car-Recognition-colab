# Car Recognition

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/KhaledMahfouz5/Car-Recognition-colab/blob/main/Car_Recognition_v2.ipynb)

A simple Google Colab–friendly project for detecting cars in images using a YOLO‑based model.  
This repository is designed to help beginners quickly run car‑recognition code without installing anything locally.

---

## 🚀 Quick Start (Google Colab)

1. Click the **Run in Colab** button above.
2. Enable GPU:
   - Go to **Runtime → Change runtime type → Hardware accelerator → GPU**
3. Run all cells.
4. Upload an image when prompted.
5. View the detection results.
